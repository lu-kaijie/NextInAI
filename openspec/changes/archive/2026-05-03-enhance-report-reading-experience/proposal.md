## Why

当前 Web 端“AI 报告抓取与解读”区域的信息覆盖、浏览方式和解读深度都偏弱：来源不够多、列表展示过于表格化、详细解读仍像摘要而不是专家带读。随着 NextInAI 逐步走向真正的情报 agent，这块需要从“能看报告”升级为“能持续发现、浏览、筛选并按需深读报告”。

现在就做这次改造，能直接提升报告侧的可用性，也能把后续的报告导出、交互问答和深度研究流程建立在更合理的 UI 与能力模型上。

## What Changes

- 扩展默认 AI 报告来源，增加更多公司、研究社区和讨论社区的信息覆盖。
- 重做 Web 端“最近报告”展示，不再用数据表格，而改成多卡片并排、可展开/折叠的浏览方式，并隐藏 `report_id`。
- 将当前卡片中的 summary 与详细解读职责拆开：列表区只做概览，详细区通过显式点击触发生成“专家带读式”深度解读。
- 新增按需生成的长篇深度解读流程，输出逐段说明、解析和评论，并支持生成后导出。
- 保留现有抓取与摘要能力，但把默认体验改为“先快速浏览，再点开深读”，避免页面初始就堆叠过长内容。

## Capabilities

### New Capabilities
- `report-source-expansion`: 定义系统如何扩展和组织更多 AI 公司、研究组织与社区报告来源。
- `report-reading-workbench`: 定义 Web 端报告浏览区的卡片化、可折叠、非表格化交互体验。
- `on-demand-deep-report-reading`: 定义用户如何按需生成专家带读式深度解读，并进行导出。

### Modified Capabilities
- 无

## Impact

- 受影响代码主要在 `src/nextinai/web/streamlit_app.py`、报告抓取/展示相关 service、报告导出与解读流程，以及相应测试。
- 需要扩展默认来源配置，并引入“摘要概览”和“按需深读”两层报告内容模型。
- Web 前端交互会有明显变化，报告部分从表格模式改为卡片/并排展开模式。
